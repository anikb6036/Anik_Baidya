# 🚀 Anik Baidya – QA Engineer Portfolio

A modern and interactive personal portfolio website for showcasing QA Engineering, Test Automation, and SDET expertise. Built with pure HTML, CSS, and JavaScript with a futuristic UI, animations, and responsive design.

---

## 🌐 Live Features

- 🔐 Login Authentication Overlay
- 🎨 Modern Dark UI with Purple Neon Theme
- ✨ Animated Particle Background
- ⌨️ Typing Animation Effect
- 📊 Animated Skill & Stats Counters
- 📱 Fully Responsive Design
- 🚀 Smooth Scroll & Reveal Animations
- 🧪 QA/SDET Focused Portfolio Sections
- 📂 Project Showcase
- 📞 Contact Section with Social Links
